Problem

读过的论文，不该每次都从头找起。

论文笔记通常按主题散落在多个 Markdown 文件里。检索工具能找到片段，却不知道你上周读到哪里；聊天工具能总结，却容易脱离原文。

01

回忆成本高

「上次读到哪、下一步做什么」要么翻文件，要么凭记忆。读到一半停下，下次启动的成本比继续阅读本身还高。

02

计划不连续

每次做阅读计划都重新翻库，已经开始的论文和没开始的论文混在一起，顺序每天都不一样。

03

证据与生成脱节

普通检索只给片段，模型总结又可能编造。读者需要能点回章节和行号的结论，而不是一段无法核对的文字。

Workflow

一次阅读，五个连续动作。

所有检索结果都会进入计划、速读或综述；所有阅读状态都会写回记忆。没有只为演示而存在的步骤。

导入

解析 front matter 与章节，写入嵌入式 seekdb。

检索

全文、标签、年份、状态与向量排名做 RRF 融合。

计划

目标标签、阅读进度和检索结果共同决定下一篇。

综述

分块交给模型，结论必须绑定真实引用编号。

写回

进度与摘要写入 PowerContext，重启后继续。

Product

看得见的检索，接得上的阅读。

工作台不是聊天框。它把资料库、计划、出处、会话和记忆放在同一套页面里，方便读者核对每个结论从哪里来。

/ask?q=rerank in RAG

带引用的中文综述

模型生成 · 覆盖率阈值 50% · 引用全部映射到检索分块

Rerank 在 RAG 中主要解决上下文污染：第一阶段检索为降低成本通常牺牲精度，无关段落会占用生成器的有限上下文。C3

它通过更强的模型联合分析 query 和 passage，对候选重新排序；实验中 rerank 提高了 nDCG@10，并减少了上下文中的无关段落。C1C5

Rerank 不能解决召回缺失：如果候选列表里没有相关段落，reranker 也无法把它找回来。C4

引用校验不通过或模型不可用时，自动回退为带出处的抽取式摘要。

Technology

两种技术，一条清晰的边界。

seekdb 是资料与证据层，PowerContext 是阅读上下文层。它们都改变产品行为，也都留下可重跑的记录。

Storage & Retrieval

seekdb

嵌入式运行，保存论文元数据、章节分块和两种索引。检索结果直接决定计划顺序、速读内容与综述引用。

  • FULLTEXT：标题与章节全文索引，保护精确术语和标识符。
  • 结构化过滤：标签、年份、阅读状态在 SQL 层完成。
  • HNSW 向量索引：1536 维余弦距离，补足改写后的语义候选。
  • RRF 融合：按排名而非不可比的原始分数合并两路结果。
Memory & Context

PowerContext

保存阅读目标、偏好、进度和会话摘要。进度通过原子记忆 artifact 的 ETag 修订，重启服务后仍能读回。

  • scope：一个工作台对应一个固定的记忆空间。
  • 原子记忆：goal、profile、progress、session 四类条目。
  • 版本修订：结束会话后进度从 rev 1 递增到 rev 2。
  • 语义召回：hybrid 检索把进度排在同一条中文问句的第一名。

seekdb 决定这次能引用什么，PowerContext 决定这次从哪继续。

Run

从空状态，跑出同一份结果。

需要 Python 3.11+ 与 uv。seekdb 以嵌入式库运行，不需要 Docker；模型密钥可选，缺失时自动使用全文检索与抽取式摘要。

# 1. 安装应用与 PowerContext
cd qoder/app
uv sync --extra dev --extra server

# 2. 配置模型（可省略）
cd ..
cp .env.example .env
#    填入 MINIMAX_API_KEY / MINIMAX_BASE_URL / MINIMAX_MODEL

# 3. 从空状态跑完整场景
scripts/run_scenario.sh

# 4. 打开工作台
#    http://127.0.0.1:8080/

运行后会看到

  • PowerContext 在 127.0.0.1:8011 就绪；配置 MiniMax 密钥后，嵌入模型为 embo-01（1536 维）。
  • 导入 6 篇、30 个分块、30 个向量，seekdb 数据落在 qoder/.runtime/seekdb。
  • 评测断言 recall@5 ≥ 0.9、MRR ≥ 0.6。
  • 8 个 Web 页面返回 200，首页显示「继续上次」。

完整排错与重置步骤见仓库 qoder/RUNBOOK.md。验证语料由本项目编写，不含第三方论文全文。
