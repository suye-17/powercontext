### PowerContext：上下文管理工程（共 11 题）
PowerContext 方向聚焦大模型与 AI Agent 的上下文工程，围绕上下文的采集、解析、组织、检索、压缩、记忆更新和运行时注入，设置 11 道不同难度的赛题。

参赛选手可从以下方向开展实践：

+ 多源上下文接入、解析与结构化；
+ 相关性检索、排序与任务匹配；
+ 长短期记忆管理与动态更新；
+ 上下文冗余及冲突处理；
+ 上下文压缩、预算控制与运行时注入；
+ Agent 场景中的动态上下文编排。

该方向重点考察选手对上下文生命周期和 Agent 工作机制的理解，以及在功能正确性、上下文相关性、任务效果、推理成本、工程质量和可解释性等方面的综合能力。优秀成果有机会沉淀为开源项目的正式贡献，并在真实业务与 Agent 应用场景中进一步落地。
