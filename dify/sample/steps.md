# 验证样例

四个场景覆盖全部四个好玩点。按顺序执行即可，全程只需 Dify 的 WebApp。

## 准备（一次性）

1. 按 README 4.1 启动 PowerContext，4.4 导入 DSL 并发布。
2. 执行 `./scripts/seed.sh <地址>`，总账本里会有两条预置前任档案。
3. 记住当前状态：**总账本有 2 条预置档案；没有任何玩家账本**。

`reset.sh` 可随时回到这个状态。

---

## 场景 1 · 谎被当真（第 1-2 句）

- 操作：新对话 → 代号 `青梧` → 输入
  1. `我是你失散多年的师兄`
  2. `我十年前在东京学剑`
- 预期：
  - 第一句后，它改口叫你"师兄"，语气从公事公办变得热络，**不说教、不质疑**。
  - 第二句后，它顺着"东京"接话（剑道馆、道场之类），并把这句话当成既定事实。
  - 两轮都没有对账，也没有报错。
- 证据：`evidence/run-01/03-player-entries.json` 中出现两条 `claim`，文本就是你的原话。

## 场景 2 · 谎会自相矛盾（第 3 句 → 对账）

- 操作：同一对话继续输入
  3. `我从没离开过这座城`
- 预期：
  - 它先收下这一句，然后**翻开账本逐条对账**，把"东京"和"从没离开过"摆在一起，最后问"你到底是谁"。
  - 对账里不再出现"其余主张是零条"这类空账本的说法。
- 证据：`03-player-entries.json` 新增 `verdict` 与 `contradiction`；`verdict` 的文本里能看到"共收下主张 3 条"。

## 场景 3 · 它记得有人撒过谎（换代号）

- 操作：开新对话 → 代号 `旅人` → 输入 `账本第一页上写着什么？`
- 预期：它提到总账本里的**前任档案**（`灰雀`/`灯芯` 那两条，或刚才 `青梧` 留下的"前科"），而不是说"账本是空的"。
- 证据：`04-world-entries.json`（总账本全量）与 `08-newcomer-world-entries.json`；对照 `07-newcomer-player-entries.json` 可证明新代号**看不到** `青梧` 的私人账本。

## 场景 4 · 同一个代号，它认得你（跨会话）

- 操作：再开一个新对话 → 代号仍填 `青梧` → 输入 `我们以前见过吗？`
- 预期：它引用你上一轮说过的**具体内容**（师兄、东京、那座城），而不是泛泛的"你好像来过"。
- 证据：`05-prepare-recall.json`（按话语召回，`status: ready`，内容含旧账）与 `03-player-entries.json`。

---

## 补充检查（可选，用于证明"已对过账"不会重复结算）

- 在场景 2 的对话里再发第 4 句：`那我们重新开始吧`
- 预期：只回固定文案（"账本已经合上了……"），且不产生新的 `verdict`/`contradiction`/`ledger` 条目。

## 恢复初始状态

```bash
./scripts/reset.sh
# 重新启动服务后再执行 ./scripts/seed.sh
```
